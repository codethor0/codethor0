Independent security researcher. I work on containment and verification of autonomous AI agents, cryptographic interlocks, and reproducible security research.

## Selected projects

- [llm-agent-control-plane](https://github.com/codethor0/llm-agent-control-plane): defensive reference implementation that keeps authorization, policy, approval, and audit logging outside the model for tool-connected LLM agents.
- [model-identity-verifier](https://github.com/codethor0/model-identity-verifier): command-line tool that checks whether a language model identifies itself consistently and flags route, provider, or downgrade signals.
- [rte-a-reference](https://github.com/codethor0/rte-a-reference): reference implementation of the Red Team Engineering Algorithm with attributed tasking, tamper-evident audit logs, and ephemeral infrastructure.
- [db-access-lab](https://github.com/codethor0/db-access-lab): disposable PostgreSQL lab for evaluating third-party products that request database access.
- [dockercomms](https://github.com/codethor0/dockercomms): OCI-native secure file transport with signed artifacts.
